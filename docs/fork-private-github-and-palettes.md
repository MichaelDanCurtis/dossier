# Private repository research and app color palettes

Career → Repositories accepts a fine-grained GitHub token, with setup guidance for selected repositories and Contents: read-only. The existing public discovery and selected-excerpt flows remain available. A token is validated with GitHub, encrypted under a separate AES-GCM key purpose on this account's private instance, and never sent to a model or returned to clients. The connection and its repository selections are installation settings: excluded from data exports and retained on data import; Delete everything removes them.

The GitHub token controls upstream access. CareerAI also requires an explicit local repository selection, keyed by repository identity. All requests use GET against the fixed GitHub API origin with redirects refused. A preview pins README and optional ARCHITECTURE.md/docs/architecture.md excerpts to a commit, with at most three documents, 16,000 characters in the snapshot and a 256 kB transport limit per response. Common credential forms and private-key blocks are redacted before preview/storage. Review the excerpts before explicit approval to send them to the selected AI provider.

Token rotation clears selections and invalidates old private previews. Removing a repository or disconnecting blocks future private analysis; saved conversations remain in private history. Already sent requests cannot be recalled. GitHub token revocation itself is performed in GitHub's settings. No cookies are transferred, no code is cloned/executed, and no GitHub write operation is implemented.

Repository research remains a conversation about personal contribution, decisions, outcomes, dates and what may be shared. A repository capability is not personal evidence. PROJECT/UPDATE proposals require supporting user answers and separate acceptance. Private repository links are omitted from proposed Profile projects. LinkedIn wording stays a draft for review and manual use; no publishing action is added here.

Appearance offers Studio, Editorial, Ocean, Forest, Violet, Rose, Ember and Graphite. Every palette supports light, dark and follow-system modes, with paired previews, Apply/Cancel and browser persistence. Studio remains the default. The app and companion login/admin pages share the canonical CSS palettes and allowlist; resume document themes remain separate.

Validation covers token encryption/non-disclosure/export exclusion, repository selection, pinned documentation, credential redaction, token rotation/disconnect, fixed-origin GET requests, all eight palettes in both modes, text/button contrast, browser persistence and account-page rendering. Local browser verification uses a separate database, fake GitHub responses and a mocked AI endpoint. A live private GitHub connection requires the user to create a scoped token and enter it directly into CareerAI.
